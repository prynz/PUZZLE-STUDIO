# Design-Konzept – Mockups

> ⚠️ **Alle Bilder in diesem Ordner sind KONZEPT-MOCKUPS.**
> Sie sind **keine Screenshots der App** und dokumentieren keinen Implementierungsstand.
> Echte Screenshots aus Simulator/Emulator/Gerät liegen ausschließlich unter `docs/previews/screenshots/`.

Erzeugt mit `pnpm design:preview` aus [`scripts/design-preview/`](../../../scripts/design-preview/) (HTML/SVG, gerendert mit Playwright/Chromium).
